# Single-Cell RNA-seq Analysis

This folder contains the single-nucleus RNA-seq workflow used to analyze cell-type-specific changes in Alzheimer's disease.

## Methods

- Quality control and preprocessing
- PCA dimensionality reduction
- UMAP visualization
- Cell-type analysis
- Cellular composition analysis

## Tools

- Python
- Scanpy
- AnnData

## Dataset

Single-nucleus RNA-seq data obtained from NCBI GEO (GSE243292).
