# Alzheimer's Multi-omics Analysis

Computational analysis of Alzheimer's disease using bulk RNA-seq, single-cell RNA-seq, alternative splicing analysis, and machine learning.

## Project Overview

This project investigates molecular changes associated with Alzheimer's disease using transcriptomic approaches across multiple biological scales.

The analysis includes:

- Bulk RNA-seq differential gene expression analysis
- Alternative splicing analysis
- Single-cell RNA-seq analysis
- Machine learning classification of disease-associated patterns
- Gene pathway interpretation

## Methods and Tools

### Bulk RNA-seq
- STAR alignment
- DESeq2 differential expression analysis
- rMATS alternative splicing analysis
- maser splicing visualization

### Single-cell RNA-seq
- Python
- Scanpy
- AnnData
- UMAP visualization
- Cell-type analysis

### Machine Learning
- scikit-learn
- Logistic Regression
- Feature importance analysis
- Model evaluation

## Data Sources

RNA-seq datasets were obtained from publicly available NCBI GEO resources.

## Reproducibility

Analysis scripts, command histories, and key output files are included in this repository to document the computational workflow.
